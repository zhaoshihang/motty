## Windows 个人版

- 新标签页的「快捷」可以保存项目名称、目录和本地终端。选择快捷项即可用指定的 Shell 打开该目录。修复了选择目录后文件夹对话框反复弹出的问题。
- Windows 11 的资源管理器一级右键菜单支持在所选目录、目录背景和驱动器上打开 Motty。Windows 10 使用经典右键菜单。
- AI 助手使用新图标。Codex CLI 支持从已安装的 CLI 读取模型，高风险操作可悬停问号查看判定理由。
- SFTP 支持内置编辑器及通过 VS Code Remote - SSH 打开远程文件和目录。
- 更新源默认使用个人 fork，可在「设置 → 关于」维护地址，检查到版本后可打开对应发布页。精简了工具栏及关于页的外部链接。

## 下载安装

Intel 或 AMD 的 64 位电脑选 `amd64-setup.exe`，Windows on ARM 选 `arm64-setup.exe`。同架构的 ZIP 为便携版，解压后运行 `motty.exe`。升级便携版时请保留原有的 `motty-data` 目录。各下载文件的 SHA-256 列于 `SHA256SUMS`。

本版使用个人代码签名证书。本机尚未信任该证书时，Windows 可能显示未知发布者。Windows 11 一级菜单需要信任安装目录下的 `motty.explorer\Publisher.cer`。该证书的 SHA-256 为 `E47F6E79A589741C78B38E1BE55EA298F04CDF1BF675988B735B3324E0D40AC9`。如选择启用，请核对指纹并将公钥导入 Windows 的「受信任的人」，再从安装目录运行 `.\motty.exe --register-shell-menu`。移除菜单用 `.\motty.exe --unregister-shell-menu`。

## 设置和快捷项备份

安装目录和便携包中的 `settings-gist.ps1` 支持将界面、终端、更新源、键盘快捷键及命名本地快捷项备份到个人 GitHub 的非公开 Gist。脚本在本地使用 Argon2id 和 AES-256-GCM 加密，通过 Git Credential Manager 的 GitHub 登录上传，并回读解密逐项校验。备份范围不含主机、登录凭据、笔记和会话。

在安装目录执行以下 PowerShell 命令。首次备份使用当前账号保存在 Git 中且具有 Gist 权限的 GitHub 登录。日后运行同一条命令即可更新备份。

```powershell
.\settings-gist.ps1 -Action Backup -Database "$env:APPDATA\motty\config.db"
.\settings-gist.ps1 -Action Verify
```

首次运行生成的恢复文件在 `%LOCALAPPDATA%\MottySettingsBackup\recovery.json`，其中有 Gist 标识和恢复密钥。请单独保存一份到自己的密码管理器或加密存储。换机时取回此文件，登录相同 GitHub 账号，退出目标 Motty 后运行以下命令。恢复会替换备份范围内的设置，保留目标数据库中的其他内容。快捷项使用原目录和 Shell 路径。

```powershell
.\settings-gist.ps1 -Action Restore -RecoveryFile .\recovery.json -Database "$env:APPDATA\motty\config.db"
```
